# CLAUDE_CONTEXT.md — Bond-Family No-Arbitrage Project

## What This Is

A research note asking: does the bond market need a bank account?

In a bond market, each tradable zero-coupon bond $p(\cdot,T)$ provides a
natural numéraire and a $T$-forward measure $Q^T$. The note asks what the
family $\{Q^T\}$ implies by itself, without assuming a risk-neutral measure
or a bank account, and in particular whether it implies one.

## Identity (changed 2026-09-17)

The paper moved from a *question paper* (open problem, empirical
illustration used to argue the question has content) to a *theory note*
(settled answer, three layers). See paper.md's own Section 1.3 ("What Is
Ours and What Is Not") for the exact contribution ledger and attribution.
Do not describe this as an open-problem paper.

## Empirical Exercise (Section 5, supporting only)

Documented for transparency and reproducibility; it is not evidence for or
against the paper's theorems, which are proved constructively. Kept from the
earlier "question paper" phase of the project.

### Principle
Calibrate local pricing measures *independently* for different maturity
segments, then check whether they cohere. Bottom-up test, not top-down.

### Test 1: Market Price of Risk Stability
- Segments $I_k = [0, T_k]$, $T_k = 5, 10, 15, 20, 25, 30$ years
- Two-factor Gaussian HJM per segment → market price of risk $\lambda^{(k)}$
- $H_0$: $\Delta\lambda = 0$ across segments — rejected 13/15 pairs
  (Bonferroni 5%); gap monotone in segment distance

### Test 3: Three-Factor Robustness
- Adds curvature factor $\sigma_3(\tau) = \sigma_3\tau\exp(-\kappa_3\tau)$
- Long-end gaps ($\ge$15Y) vanish with 3 factors (model inadequacy);
  short-vs-long gaps (5Y vs $\ge$10Y) persist and widen (structural)

### Model
Two-factor Gaussian HJM (baseline):
  $df(t,T) = \mu(t,T)\,dt + \sigma_1 e^{-\kappa_1(T-t)}\,dW_1 + \sigma_2 e^{-\kappa_2(T-t)}\,dW_2$

All computations closed-form (Gaussian integrals). No Monte Carlo.

### Data
ECB daily zero-coupon yield curves, EUR AAA-rated government bonds.
Maturities (12 series): 3M, 6M, 1Y, 2Y, 3Y, 5Y, 7Y, 10Y, 15Y, 20Y, 25Y, 30Y.
Period: January 2014 – December 2024 (2,805 trading days).
Source: https://data-api.ecb.europa.eu/ (public, no API key required)

## Reproducing Results

```bash

conda create -n bondna python=3.11 -y
conda activate bondna
pip install -r requirements.txt

# 2. Data (ECB public API, no key required)
python src/data/fetch_ecb.py          # -> data/ecb_yield_curves.parquet

# 3. Exercises
python src/tests/test1_lambda_gap.py  # -> data/test1_results.parquet, test1_summary.csv
python src/tests/test1_robust_kappa.py
python src/tests/test3_robustness.py  # -> data/test3_summary.csv, test3_vs_test1.csv

# 4. PDF
conda install -c conda-forge pandoc tectonic -y
cd paper && make pdf
```
